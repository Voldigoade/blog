一个新的动画的宣布往往伴随着相同的信息:一个日期,一个论文,几个名字和一个工作室。

问题在于,一个名单的名单几乎没有告诉任何人谁不花他的日子阅读日语。

为 **英文名称:SSS Class Revival Hunter**然而,目前已有几个关键位置。

有些名字值得我们停下来。

这篇文章不包含 **史上没有 spoiler**是。 我们只谈论制作动画和正式宣布的信息。

## STUDIO FU 接收命令

动画的 *英文名称:SSS Class Revival Hunter* 被委托 **工作室FU**.

这可能是广告中最不即时可识别的名称,尤其是因为它还没有MAPPA、Madhouse、Bones或Ufotable等工作室的国际知名度。

STUDIO fu 是一家位于东京Musashino的日本动画工作室。 其官方网站显示了最近各式各样的作品的参与,但 *英文名称:SSS Class Revival Hunter* 这是一个特别有趣的制作,因为这里的工作室是明确信用的动画系列。 

但是,在谈论动画时,我们必须避免一个非常常见的错误:

**工作室的名称不允许,单独,预测最终质量。**

动画系列很大程度上取决于导演、动画主持人、招聘的独立动画家、日历、预制作以及各队的节目分布方式。

一个大型工作室可以制作一个技术上不规则的系列。

一个不太熟悉的工作室可以产生一个很好的惊喜。

为 *英文名称:SSS Class Revival Hunter*其余的团队变得非常重要。

## 希罗基·萨库拉伊(Hiroaki Sakurai)

宣布的导演是 **希拉基·萨库拉伊**.

其名称与 *此分類上一篇: The Disastrous Life of Saiki K*这是一部剧,他也担任导演。 此外,Crunchyroll在公告中直接引用了这一点。 *英文名称:SSS Class Revival Hunter*. 

动画导演的角色远远更广泛,而不是简单地“告诉动画家要画什么”。

他参与了适应的总干事:节奏,色调,舞台,视觉选择,与各部门的负责人协调,以及整体的一致性。

在适应中,困难的很大一部分也包括将思考的作品转化为被阅读的,成为被思考的,被观察的。

在 Webtoon 中的可观的垂直图像不会自动在 16:9 屏幕上产生相同的影响。

一个序列的盒子可能需要成为一个三十秒的场景。

沉默可以延长。

一个行动可以完全重新思考。

正是这样,实现工作就变得至关重要。

## 一个没有到任何地方的角色设计师

这个名字可能最吸引我的注意力在这个第一支球队是 **塔卡希罗Yoshimatsu**负责人物设计。

如果你看到很多动画,你可能已经看到他的工作,不知道他的名字。

Yoshimatsu 曾担任动画角色设计师。 **2011年《猎人》**与此同时,许多与 **超级**是。 日本官方基地JFDB批准,例如,对电影的角色设计*超级* 拍摄电影的角色设计 *猎人 / Hunter*. 

他的角色在 *英文名称:SSS Class Revival Hunter* 它将是基本的。

图形调整 Webtoon 不意味着将每个图像复制到相同的图像。

一个专为动画的角色必须能够在不同的角度,多次被许多人绘制,有时在极其快速的场景。

因此,设计师寻求平衡:

```text

identité visuelle de l'œuvre originale

              +

cohérence des personnages

              +

possibilité de les animer efficacement

```

一个令人难以置信的细节的设计可以在固定图像上是美丽的,当需要制作几千幅绘画时,它会变成噩梦。

适应的品质有时在这种看不见的妥协中发挥作用。

## 剧本将由Sayuri Oba主持

**西奥里奥巴** 这是在剧本上公布的。

在这里,它值得更多的线条在一个技术清单。

当一个Webtoon变成一个动画时,有人必须决定如何将可用的内容安排为大约20分钟的节目。

一个节目的结局在哪里?

哪些场景需要更多的呼吸?

哪些转换在一个页面上工作,但在动画中不太好?

有多少内容可以调整,而不会给出故事在其自己的终结基因之后的印象?

这些决定可以完全改变适应的观念,即使讲述的事件仍然与原创作品相同。

目前,没有足够详细的官方信息可以确定生产所选择的准确速度。

而且,这可能更好:宣布一个团队并不意味着我们可以猜测该系列将是如何结构化的。

## 上一篇: 第一天不允许审判动画

第一张图片和第一张视频在广告中发布。

它们很重要,因为它们最终给了该项目一个视觉身份,但必须保持一定的谨慎。

几秒钟就没想到:

- 整个季节的动画频率;

- 最雄心勃勃的事件;

- 最终完成水平;

- 战斗的管理;

- 绘画的稳定性;

- 真正的适应速度。

首先,提交一张制作。

这不是一个基准。

真正的材料,让你开始认真评估的调整将很可能与更长的广告带和,最重要的是,当我们会了解更多的团队成员。
